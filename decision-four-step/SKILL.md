# decision-four-step — 科学决策四步法

## R — 原文

> 扩充你的选项;用现实检验你的观点;从长远考虑;为一旦决策错误做好准备。用中国话来说,这四步就是第一奇计百出、第二实事求是、第三从长计议、第四未料胜先料败。
>
> — 希思兄弟《决断》(万维钢解读，第1讲)

---

## I — 方法论骨架

任何重大选择都可以被分解为 4 个**可独立诊断**的步骤,每一步都有对应的典型错误:

1. **扩充选项** — 不从现有选项里挑;试着加选项。错误模式: 钻牛角尖(只有 yes/no)。
2. **现实检验** — 主动向多方求证,尤其是向不熟悉但更懂行的人。错误模式: 确认偏误(只听进正面意见)。
3. **长远考虑** — 不被短期情感(高工资、害怕、报复)绑架。错误模式: 短期冲动。
4. **为错误做准备** — 决策前给失败留退路(止损点/退出条款/保底收入)。错误模式: 过度自信。

这四步**不是流程**(不必按顺序来),而是**诊断工具**:卡在哪一步就修哪一步。希思兄弟的独到之处是把"步骤"和"错误模式"配对 — 大多数决策书只讲怎么做,他们讲"四步对应的四种死法",便于自我定位。

实操上,如果你"知道自己卡住",先自问: 我是有选项没看清?(第一步) 还是选项看清了但不会判断优劣?(第二步) 还是判断清楚了但下不了决心?(第三步) 还是决心下了但没准备失败?(第四步)。

## A1 — 书中的应用

### 案例 1:普利斯特里择业 — 四步全用
- **问题**: 1772 年谢尔本伯爵 offer 250 英镑 vs 留在利兹当牧师 100 英镑
- **方法论的使用**: ① 加选项: 主动谈判远程办公 + 要 150 英镑保底;② 现实检验: 向了解伯爵的人求证人品;③ 长远考虑: 7 年合作后的生活稳定性;④ 为错误做准备: 分手后 150 英镑/年终生保底
- **结论**: 接受 offer,7 年合作期取得大量学术成果
- **结果**: 分手后伯爵果然履行保底,普利斯特里取得研究自由

### 案例 2:万维钢炒股映射四步法
- **问题**: 炒股时的本能决策总是亏损
- **方法论的使用**: ① 选股眼界要宽(扩充选项) ② 客观看待持有股票(现实检验) ③ 克服赔钱想快速捞回(长远考虑) ④ 设止损点(为错误做准备)
- **结论**: 四条规则简单但极难做到
- **结果**: 万维钢炒股失败退出,但承认这四条是科学决策的同构

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户面临 2-5 个备选的人生/职业选择,但不知如何下手
2. 用户在重大决策面前反复纠结,说不清卡在哪
3. 用户刚做完决定就后悔,怀疑决策过程有问题
4. 用户读到决策科学内容想系统化应用

### 语言信号

- "面对 X 个选择不知道怎么办"
- "人生重大选择 / 重大决定 / 关键决策"
- "决策 / 选择 / 拿主意"
- "纠结 / 下不了决心"

### 与相邻 skill 的区分

- 与 `decision-is-choice`: 本 skill 是"怎么决策",后者是"是不是真决策"。**前置调用**
- 与 `expand-options` / `reality-check` / `ten-ten-ten` / `red-team` / `probe-and-pivot`: 这些是四步法的**委派工具**;本 skill 是**总入口和编排者**
- 与 `values-decision`: 后者是第三步"长远考虑"算不清时的终局判据;本 skill 是第三步的常规路径

## E — 可执行步骤

当 skill 被激活后, agent 应按以下步骤执行:

1. **先做前提检查** — 委派到 `decision-is-choice`(确认有 ≥ 2 个真实备选)
   - 完成标准: 用户能列出 ≥ 2 个真实备选,或已经知道是"决心"直接执行
   - 判停条件: 无备选 → 调 `expand-options` 加选项,不再走四步法

2. **自问"我卡在哪一步?"** — 用 4 个错误模式(钻牛角尖/确认偏误/短期情感/过度自信)定位
   - 完成标准: 用户能说出"我卡在 X"

3. **委派到对应的专门 skill** —
   - 卡在第一步 → 调 `expand-options`
   - 卡在第二步 → 调 `reality-check` + `red-team`
   - 卡在第三步 → 调 `ten-ten-ten` + `values-decision`
   - 卡在第四步 → 调 `probe-and-pivot`(试水/止损)

   🔴 **CHECKPOINT**: 每步执行完后,问用户"这一步解决了吗?" 若未解决,继续诊断(可能多步同时卡住)

4. **为错误做准备的兜底** — 即使前面 3 步都做对,也要主动问"如果错了怎么办?"
   - 完成标准: 用户能说出至少 1 个失败应对方案

   🛑 **STOP 条件**: 若决策不可逆(婚姻、移民)且试水不可行,跳过 `probe-and-pivot`,直接调 `base-rate-forecast` 强化基础比率预测(用别人预测自己)

### if-fail 三段式兜底

| 失败信号 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户每步都说"做不到" | 提示: 这不是要求每步完美,是定位卡点。回到步骤 2,只问"最卡的是哪一步" | 若用户无法识别卡点,优先调 `ten-ten-ten`(旁观者视角) |
| 用户坚持"我都要"(逃避选) | 用 🔴CHECKPOINT: "科学决策不是选最完美的,是选最不坏的。先选一个,错了再换" | 调 `probe-and-pivot` 试水法,把决策变成动态 |
| 用户过度分析瘫痪 | 用 🛑STOP: "错比不决好"(p25)。先选一个行动,反馈来再调整 | 标注为"决策瘫痪",调用 `red-team` 强制做一次反向评估 |

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **紧急执行场景**:医疗急救、生产线故障,无时间走 4 步
- **单一选项决心**: 不可逃避的单行道,先做再说
- **信息查询类**: 没有决策在发生
- **已经走过四步仍反复回头**: 可能不是方法问题,是价值观问题,调 `values-decision`

### 作者在书中警告的失败模式

- **「无选项的决心」(ce01)**: 没有真决策,任何四步法都无效 — 走前提检查
- **「确认偏误」(ce03)**: 第二步的最大敌人,需要 `red-team` 纠偏
- **「短期情绪冲动」(ce07)**: 第三步的最大敌人,需要 `ten-ten-ten` 旁观
- **「过度自信」(ce05)**: 第四步的最大敌人,需要止损/保底
- **「知易行难」(ce17)**: 四步规则简单但实操极难 — 这是作者本人的坦白,意味着 skill 不会因"做了四步"就保证好结果

### 作者的盲点 / 时代局限

- **「四步可独立诊断」是简化**: 实际多步同时卡住很常见,本 skill 的逐步委派可能过于工整。**实操时允许并列处理**
- **「每步都能修」**: 实际有些选项天生不可加(法律/物理约束)、有些预测不可能(全新增量)。这是 BOOK_OVERVIEW 批判段指出的"被动决策法"边界
- **与「3P 决策」的内部矛盾**: BOOK_OVERVIEW 批判指出,「基础比率(信数据)」与「试水(信行动)」在信息需求上矛盾。本 skill 默认"先调研后决策",但 f18 揭示 60% CEO 决策无计划书。**适用边界: 个人/可逆决策适用,组织/不可逆决策要重写为"试水主导"**

### 容易混淆的邻近方法论

- **传统的 SWOT / 决策树**:分析结构而非决策程序,不能帮你"卡在哪步"
- **心理咨询的"决策平衡单"**:只列利弊,等同道德算数(被动决策法)
- **"直觉决策"**:强调跟着感觉走,绕过四步
