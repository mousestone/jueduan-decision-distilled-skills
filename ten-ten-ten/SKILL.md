# ten-ten-ten — 旁观者 10/10/10

## R — 原文

> 这个方法要求你从三个时间尺度去考虑一个问题:10 分钟之后,你会对这个决定作何感想?10 个月之后,你会作何感想?10 年之后,你会又作何感想?
>
> — 希思兄弟《决断》(万维钢解读，第3讲)

---

## I — 方法论骨架

当用户纠结、下不了决心时,大概率是被短期情绪(紧张、害怕、兴奋、不甘)绑架。旁观者没有这些情绪,所以更理性 — 但我们不能事事都问别人,最好的办法是**把自己变成旁观者**。

希斯兄弟提供三个互补的"旁观"技术:

1. **10/10/10 法则** — 对同一决定分别从 10 分钟/10 个月/10 年三个尺度问"我会作何感想"。短期情绪在长远尺度下往往变得不重要。安妮表白案例:10 分钟后紧张但自豪,10 个月后即便被拒也不后悔,10 年后根本不是事儿。
2. **给最好的朋友建议** — 问自己"如果是我最好的朋友面临这个选择,我会给他什么建议?"借朋友视角看自己。
3. **用外语/第二语言思考** — 实证研究发现用外语思考更利于理性决策,因为外语隔着一层不善于表达短期情绪。

三种技术不必全用,问题越情绪化越要走全套。

## A1 — 书中的应用

### 案例 1:安妮向卡尔表白
- **问题**: 36 岁的安妮想和 45 岁离异带娃的卡尔结婚,但卡尔态度不明;周末度假想摊牌但纠结
- **方法论的使用**: 希斯兄弟让她用 10/10/10:10 分钟后紧张但自豪,10 个月后即便被拒也不后悔,10 年后根本不是事儿
- **结论**: 决定摊牌
- **结果**: 截止书出版,两人虽未结婚但进展良好,安妮说成功可能性约 80%

### 案例 2:万维钢听不进朋友劝告 (炒股反例)
- **问题**: 万维钢炒股期权账户从 13 万美元跌到清零
- **方法论的使用**: 朋友劝"别做了,认识的人做期权都赔光",但万维钢没听 — 没把自己当旁观者
- **结论**: 短期暴利兴奋绑架判断
- **结果**: 账户清零

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户纠结某个选择,反复摇摆
2. 用户被短期情绪(害怕/紧张/兴奋)主导
3. 用户做了决定但总后悔
4. 用户对某事特别热情或特别抗拒

### 语言信号

- "纠结 / 下不了决心"
- "我好紧张 / 好害怕"
- "我特别想 / 我特别不想"
- "我好像不够客观"

### 与相邻 skill 的区分

- 与 `red-team`: 本 skill 是"自己做自己旁观者",后者是"找外部反对派"
- 与 `values-decision`: 本 skill 是"剥离短期情绪看清利弊",后者是"利弊算不清时用价值观终局判据"
- 与 `decision-four-step`: 本 skill 是第三步"长远考虑"的具体技术

## E — 可执行步骤

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别用户的纠结状态**
   - 完成标准: 用户能描述出短期情绪(紧张/害怕/兴奋/不甘)
   - 判停条件: 用户客观冷静,没有短期情绪 → 跳到 `decision-four-step` 第三步常规路径

2. **应用 10/10/10 法则**
   - 完成标准: 用户分别回答三个时间尺度的感受(写出/说出来)
   - 关键纪律: 三个尺度都要问,**不要**只问长期(那会忽略短期重要信号)

3. **应用"给最好的朋友建议"**
   - 完成标准: 用户能说出"如果我最好的朋友面临这个选择,我会建议他..."

   🔴 **CHECKPOINT**: 若用户说"但他/她的情况和我不一样",提示他"假设朋友和你一样的情况下" — 这是在做旁观者演练,不是真的建议朋友

4. **(可选)用外语思考**
   - 完成标准: 用户能用第二语言思考此问题,或用外语检索相关信息

### if-fail 三段式兜底

| 失败信号 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户长期尺度看不清(觉得 10 年太久) | 调小尺度:10 分钟/10 周/10 个月 — 找到他觉得能看清的时间尺度 | 若所有长期尺度都看不清,提示他"这可能不是真决策"或需要外部输入 |
| 用户三个尺度结论相反 | 列出每个尺度的真实感受,识别哪个尺度的"权重"对当前选择最重要 | 调 `values-decision` 用价值观决定哪个尺度优先 |
| 用户无法做旁观者(太投入) | 调 `red-team` 找朋友当蓝军 — 外部视角替代内部旁观 | 接受这个决策可能需要"睡一觉"再决定 |

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **紧急危机**: 没时间做 10/10/10
- **纯执行细节**: 已经决定怎么做
- **不可逆决策(婚姻/移民/创业签约)**: 长期视角可能扭曲判断,在场性需求场景不适用(ce21)
- **用户在表达情感而非求决策**: "我好难过" 不是决策问题

### 作者在书中警告的失败模式

- **「短期情绪冲动」(ce07)**: 赔钱想快速捞回,本 skill 是解法
- **「10/10/10 默认长期优于短期」(ce21)**: 在场性需求场景(陪孩子/危机处置)长期视角未必最优
- **「决策瘫痪」(ce16)**: 旁观者视角可能让用户更纠结,需要平衡
- **「不忘初衷」(ce15)**: 长期视角反而可能让用户忘记当初的热情

### 作者的盲点 / 时代局限

- **假设用户能做旁观者**: 实际深度投入的人(创业/恋爱)很难抽离
- **三个时间尺度的"权重"假设主观合理**: 实际不同决策需要不同尺度,机械套用可能误导
- **"用外语思考"假设用户会外语**: 大多数用户只有母语

### 容易混淆的邻近方法论

- **「延迟决策」(sleep on it)**: 类似但缺少具体的三个尺度框架
- **「长期主义」**: 强调长期但不一定解决短期情绪
- **「正念冥想」**: 剥离情绪但不做旁观者视角
