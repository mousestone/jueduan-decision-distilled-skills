# base-rate-forecast — 基础比率 + 特殊因素修正

## R — 原文

> 所谓基础比率,就是以前的人,做同样的事,做到的平均水平。而且卡尼曼知道,预测未来最好的参考指标,就是基础比率。
>
> 如果你不想听从基础比率,那么你就得拿出非常特殊的理由,而且这些理由必须是切实存在的和别人的不同之处。
>
> — 希斯兄弟《决断》(万维钢解读，第4讲)

---

## I — 方法论骨架

当用户在做"我会不会成功"这类预测时,最大的敌人是**过度自信** — 人人觉得自己比别人特殊,会做得比别人好。希斯兄弟给出两步预测法:

**第一步:基础比率** — 预测未来时,先看"以前的人做同样的事达到的平均水平"。这是默认预测,几乎永远应该从这里开始:
- 卡尼曼编教材:小组预测 1.5-2.5 年,基础比率显示 60% 教材用 7-10 年完成;结果真用了 8 年
- 万维钢炒股期权:朋友劝"做期权的都赔光",基础比率提示风险;万维钢没听,清零

**第二步:特殊因素修正** — 若想偏离基础比率向上修正(觉得自己会做得更好),必须拿出**切实存在的、和别人不同的**特殊因素。注意"特殊因素"的要求:
- ≠ "我比别人努力/聪明/热爱" (人人这么觉得)
- = "我的年龄/资源/经验/方法确实和平均不同,且这种不同已被验证能带来优势"
- 布莱恩骨髓移植:虽然手术基础成功率不高,但他"28 岁年轻 + 去全美最擅长医院" 两个可举证的优势 → 实际成功

判断流程:基础比率是默认;除非你能列出可举证的 2-3 个特殊因素,且每个因素都有数据/经验支持"这个因素会带来 X% 改善",否则接受基础比率。

## A1 — 书中的应用

### 案例 1:卡尼曼编教材 8 年
- **问题**: 卡尼曼小组预测教材完成时间
- **方法论的使用**: 卡尼曼问"类似教材编写平均要多久",得到 60% 用 7-10 年;小组不屑,预测 1.5-2.5 年
- **结论**: 实际用了 8 年,完全符合基础比率
- **结果**: 验证基础比率的预测力

### 案例 2:布莱恩骨髓移植
- **问题**: 28 岁布莱恩患罕见血液病,基础手术成功率不高
- **方法论的使用**: 布莱恩研究发现自己的两个**可举证**特殊因素:① 28 岁(基础比率群体是 60+ 岁)② 去全美最擅长骨髓移植的医院
- **结论**: 决定做手术,基础比率被合理向上修正
- **结果**: 手术成功,至今健康并成为大学教授

### 案例 3:餐馆三星半评分
- **问题**: 用户想去没去过的餐馆,网上评分三星半
- **方法论的使用**: 基础比率(三颗半) = 不去。但拆开看:打一星的人是因为贵不是难吃,而用户能承受价格
- **结论**: 对用户特殊因素(价格承受力)成立,基础比率被合理向上修正
- **结果**: 验证"基础比率 + 特殊因素"框架

### 案例 4:万维钢炒股清零 (反例)
- **问题**: 万维钢自认比"做期权的人"特殊
- **方法论的使用**: 没拿出可举证的特殊因素 — 只是"自我感觉特殊"
- **结论**: 基础比率未被合理修正,盲目乐观
- **结果**: 账户清零

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户预测"我能不能成功"(创业/投资/学习新技能)
2. 用户觉得自己比别人特殊(创业成功率/考试通过率/业绩)
3. 用户在评估某个新机会是否值得投入
4. 用户在做可能高估回报的决策

### 语言信号

- "我能不能成功 / 我跟别人不一样"
- "我比别人更努力 / 更聪明 / 更热爱"
- "凭什么我会更好"
- "我看到很多人失败,但我不会"

### 与相邻 skill 的区分

- 与 `reality-check`: 本 skill 用"统计平均值",后者用"外部意见"。**本 skill 量化,后者质化**
- 与 `decision-four-step`: 本 skill 是第四步"为错误做准备"前的预测工具
- 与 `probe-and-pivot`: 本 skill 评估"该不该做大投入",后者把决策变成"小规模试探"

## E — 可执行步骤

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别用户在预测什么**
- 完成标准: 用户能明确说出"我预测 X 会发生 / 我会成功"

2. **查找基础比率**
- 完成标准: 用户找到"以前的人做同样的事达到的平均水平"(可来自研究/数据/常识)
- 关键纪律: 若找不到基础比率,标注为"全新增量",调 `probe-and-pivot` 走试水

3. **列出用户"特殊因素"**
- 完成标准: 用户列出至少 2-3 个"我和别人不同的因素"
- 判停条件: 用户说"我和别人一样" → 接受基础比率

4. **检验特殊因素是否"可举证"**
- 完成标准: 每个特殊因素都能回答"为什么这个因素会让我做得更好?有数据/经验支持吗?"
- 关键: "我感觉"不算举证;有数据/经验/可验证的差异才算

   🔴 **CHECKPOINT**: 若用户的特殊因素都是"我更努力/聪明/热爱",提示他"这些是人人都会觉得的,不是真正的特殊因素" — 参考万维钢炒股反例

5. **综合判断**
- 完成标准: 用户能说出"基于基础比率 X + 特殊因素 Y,我预测 Z"

### if-fail 三段式兜底

| 失败信号 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 找不到基础比率 | 标注"全新增量",调 `probe-and-pivot` 走试水 | 若领域完全无先例,接受"无基础比率可参考",决策改为"小步快跑" |
| 特殊因素都是主观感觉 | 提示"特殊因素必须可举证:年龄/资源/方法/经验等客观不同",要求重列 | 若用户仍只能主观感觉,提醒他"你的特殊因素不特殊,接受基础比率" |
| 基础比率和特殊因素都指向失败 | 调 `probe-and-pivot` 看能否小规模试探 | 接受预测为负,问用户"明知可能失败还做吗?" → 调 `values-decision` 看是否值得 |

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **全新增量场景**: 没有基础比率可查,调 `probe-and-pivot`
- **纯信息查询**: 没有预测在发生
- **不可逆决策**: 基础比率虽好但仍是统计,不可逆决策要加 `red-team` 多重防护
- **用户在表达感受而非求预测**: "我担心失败" 不是预测问题

### 作者在书中警告的失败模式

- **「过度自信」(ce05)**: 万维钢炒股清零
- **「对基础比率不屑一顾」(ce06)**: 卡尼曼小组预测 1.5-2.5 年不屑基础比率
- **「伪特殊因素」(ce08)**: 主观感觉不是真正的特殊
- **「基础比率 vs 试水矛盾」(ce19)**: 基础比率告诉你"会失败",试水告诉你"先做再说" — 这是 BOOK_OVERVIEW 批判段指出的内部矛盾。**调用本 skill 时,要标注"试水可能推翻基础比率"**

### 作者的盲点 / 时代局限

- **基础比率假设数据可得**: 实际很多场景无可靠基础比率
- **特殊因素"可举证"假设数据支撑**: 实际很多优势很难量化
- **统计平均的"基线谬误"**: 基础比率对个人可能误导 — 一个 100% 会死的统计平均值,可能某人有 1% 存活率,这是关键差异。**特殊因素修正时要小心"幸存者偏差"**

### 容易混淆的邻近方法论

- **「概率思维」**: 类似但缺少"基础比率优先"的具体路径
- **「参考类别预测」(reference class forecasting)**: 类似,本 skill 是其简化版
- **「SWOT 中的优势」**: 列优势但不要求"可举证"
