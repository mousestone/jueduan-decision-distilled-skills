# values-decision — 价值观优先级

## R — 原文

> 这里所谓的价值观,就是你设定的"优先级"(priority)是什么样的,说白了你认为什么重要,什么不重要。如果不能两全,你认为事业的成功对你最重要,还是家庭幸福对你最重要?
>
> — 希思兄弟《决断》(万维钢解读，第3讲)

---

## I — 方法论骨架

利弊分析有极限:有些两难选择,无论怎么算都"差不多"(事业 vs 家庭 / 自由 vs 安全 / 短期 vs 长期)。这时不能再依赖利益计算,必须回到**价值观/优先级**做终局判据。

希斯兄弟重新定义"价值观":
- ≠ 道德说教("做好人""不撒谎")
- = 你设定的"什么重要、什么不重要"的**优先级**
- 完全是个人的选择,没有标准答案

典型应用:
- 个人:事业成功 vs 家庭幸福,自由 vs 安全,创造 vs 稳定
- 企业:消费者满意 vs 股东满意 vs 员工满意(美联航案例)

实操三个动作:
1. **承认两难**(利弊算不清是正常的)
2. **明确优先级**(什么对你最重要)
3. **选择匹配项**(按优先级选)

关键纪律:价值观不是空话,**可以指导决策**;且要"不忘初衷"——一般人做着做着就忘了自己的优先级而随波逐流,需要时不时反省。

---

## A1 — 书中的应用

### 案例 1:美联航拉乘客下飞机
- **问题**: 美联航为了给员工让座,暴力拖乘客下飞机
- **方法论的使用**: 暴露了企业的价值观混乱:消费者满意 vs 员工满意 — 没明确优先级导致现场决策灾难
- **结论**: 企业必须**事先**把价值观/优先级跟员工说清
- **结果**: 美联航公共关系危机;验证"事先明确优先级"的必要性

### 案例 2:事业 vs 家庭 / 公务员 vs 一线城市
- **问题**: 一些读者(李振鹏等)面临"稳定 vs 闯荡"的两难
- **方法论的使用**: 希斯兄弟说,这种问题最后是"两难选择",事实上有人当公务员当得很好,有人闯荡也闯荡得很好
- **结论**: 没有标准答案,只能回归个人价值观
- **结果**: 没有"正确"答案,只能选匹配自己价值观的

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 用户利弊分析后说"两个都很好/两个都很差"
2. 用户在两难选择面前反复纠结(事业/家庭/自由/安全)
3. 用户在做可能影响一生的选择但算不清
4. 用户在企业/团队层面要明确价值观

### 语言信号

- "两个都很好 / 两个都很差"
- "我没法判断哪个更好"
- "事业 vs 家庭"
- "什么是更重要的"
- "怎么选都没错"

### 与相邻 skill 的区分

- 与 `ten-ten-ten`: 后者剥离短期情绪,本 skill 在情绪剥离后仍算不清时用
- 与 `decision-four-step`: 本 skill 是第三步"长远考虑"算不清时的终局判据
- 与 `compare-side-by-side`: 后者给"如何比较",本 skill 给"用什么判据比"

## E — 可执行步骤

当 skill 被激活后, agent 应按以下步骤执行:

1. **确认利弊已无法解决**
- 完成标准: 用户尝试过利弊分析、矩阵打分,仍无法决定
- 判停条件: 利弊能解决 → 回到 `compare-side-by-side` 收紧

2. **识别用户的优先级维度**
- 完成标准: 用户列出至少 3 个"对我重要的维度"(可包括事业/家庭/自由/安全/创造/稳定/意义/收入等)

3. **明确优先级排序**
- 完成标准: 用户能给这些维度排序(最重要 → 最不重要)

   🔴 **CHECKPOINT**: 若用户说"都重要",提示他"必须排序,因为资源有限" — 价值观不是空话,要可操作

4. **按优先级匹配选项**
- 完成标准: 用户能说出"基于优先级 X,选 A 不选 B"

### if-fail 三段式兜底

| 失败信号 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户拒绝明确优先级 | 提示"价值观不是空话,可以指导决策",给他具体场景:家庭紧急需要钱 vs 想做有意义的低收入工作 | 若仍拒绝,接受他处于"价值观未明"阶段,建议先不定重大决策,做小决策练手 |
| 排序反复变动 | 检查排序的"测试"——用户能用什么标准判断 A 比 B 重要? | 若无标准,提示他"价值观需要时间沉淀,不必现在定" |
| 选项与多个优先级冲突 | 列出每个优先级对应的选项得分,加权打分 | 若仍冲突,提醒用户"有些决策注定两难,选最不能失去的" |

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **纯利益计算就能解决**: 还在 `compare-side-by-side` 阶段
- **用户在执行细节**: 已经决定,怎么做不是本 skill
- **用户在表达感受而非求决策**: "我好矛盾" 不是决策问题,需要先心理支持
- **价值观未明且不愿沉淀**: 用户必须接受"价值观需要时间"

### 作者在书中警告的失败模式

- **「价值观=道德说教」(ce 隐含)**: 实际是优先级,不是道德
- **「不忘初衷很难」(ce15)**: 价值观要时不时反省,否则被随波逐流覆盖
- **「决策瘫痪」(ce16)**: 价值观不能成为无限纠结的借口

### 作者的盲点 / 时代局限

- **假设价值观可"识别"**: 实际很多人没清晰价值观
- **假设价值观"稳定"**: 实际价值观会随经历变化
- **"价值观=优先级"是简化**: 实际很多决策涉及**价值冲突**(不能说哪个优先级更高) — 这需要更多工具

### 容易混淆的邻近方法论

- **「道德决策」(ethics)**: 关注"对错"非"优先级"
- **「使命宣言」(mission statement)**: 形式相似但企业场景
- **「效用主义」(utilitarianism)**: 计算总福利但忽略个体优先级
